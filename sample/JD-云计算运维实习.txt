云计算运维实习生（2025 届）

岗位职责：
1. 负责公司云主机、容器集群的日常运维，保障线上服务稳定运行；
2. 参与监控体系建设，负责 Prometheus / Grafana 告警规则配置与优化；
3. 参与自动化运维脚本开发，减少重复性人工操作；
4. 参与线上故障排查，输出故障复盘文档。

任职要求：
1. 计算机相关专业本科及以上学历，2025 届毕业生优先；
2. 熟悉 Linux 操作系统，掌握常用命令、systemd、网络排查工具（ss/tcpdump）；
3. 熟悉 Shell / Python 至少一种脚本语言，能编写自动化脚本；
4. 熟悉 Docker 容器化，了解 Kubernetes 集群部署与常用对象（Deployment / Service / Ingress）；
5. 了解 Nginx 配置、MySQL 基础运维、Redis 常用命令；
6. 有 Prometheus、Grafana、ELK 等监控日志系统使用经验者优先；
7. 有 CKA / HCIA 等认证者优先；
8. 每周可实习 4 天以上，可实习 6 个月以上者优先。

加分项：
- 有 CI/CD（Jenkins / GitLab CI）流水线搭建经验；
- 有故障排查实战经验，能讲清楚一次完整的问题定位过程；
- 有开源项目或技术博客。
