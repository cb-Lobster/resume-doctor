# 优秀写法范例（改写参考）

## 项目经历：弱 → 强
- 弱：负责搭建 Kubernetes 集群，学习了相关运维知识。
- 强：基于 3 台 4C8G 云主机用 kubeadm 搭建 K8s 1.28 集群，配置 Calico 网络与 Nginx Ingress，承载 12 个业务 Pod；通过 Prometheus + Grafana 监控节点资源，定位并解决 2 次 Pod 频繁重启（OOM），使服务可用性从 98% 提升到 99.9%。

## 实习经历：弱 → 强
- 弱：在运维部实习，参与了日常巡检和故障处理。
- 强：实习期间负责 30 台 Linux 服务器的日常巡检，用 Python + Shell 将手工巡检脚本化（覆盖磁盘、负载、证书到期等 9 项检查），单次巡检耗时从 90 分钟降到 6 分钟；参与 1 次线上 Redis 内存告警处理，通过分析 slowlog 定位到批量写入脚本，调整为 pipeline 后 QPS 提升约 3 倍。

## 技能栏：弱 → 强
- 弱：熟悉 Linux、Docker、K8s、MySQL，有较强的学习能力。
- 强：Linux（熟练：常用命令、systemd、网络排查 tcpdump/ss）；Docker（熟练：镜像分层优化、compose 编排）；K8s（熟悉：kubeadm 部署、Deployment/Service/Ingress、HPA 弹性伸缩）；MySQL（熟悉：索引优化、慢查询分析，处理过 2000 万行表的查询优化）。

## 教育背景：补充要点

## 单条 bullet 的通用模板
动作动词 + 对象/规模 + 方法/技术 + 结果（数字 + 对比基线）。
例：用（方法）对（对象，含规模）做（动作），使（结果指标）从 A 变成 B。

## 改写红线
- 只能调整表达方式与结构，不得新增用户未提供的经历、数字、证书、公司名。
- 若原文缺少关键数字，改写稿中用【请补充：集群节点数】这样的占位符提示用户自己填，不许编造。
